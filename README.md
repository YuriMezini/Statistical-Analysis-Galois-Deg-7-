# Statistical-Analysis-Galois-Deg-7
# Statistical Analysis of Non-\(S_7\) Galois Groups

This repository contains a Jupyter notebook that performs a statistical study
of the non-\(S_7\) part of the AIMS-7 database of irreducible septic polynomials.
The code produces the figures used in the “statistical analysis” section of my paper.

---

## Contents

- `Stats-AIMS-7.ipynb`  
  Main notebook. Loads the data, computes heights and basic statistics, and
  generates all plots.

- PNG figures (generated by the notebook):
  - `group_distribution_pie.png`
  - `height_distributions_by_group.png`
  - `height_boxplots_by_group.png`
  - `mean_height_by_group.png`
  - `height_vs_complexity_scatter.png`
  - `mean_height_vs_complexity.png`
  - `discriminant_distribution.png`
  - `height_vs_discriminant.png`


---

## Data

The notebook expects a CSV file containing the non-\(S_7\) part of the AIMS-7
database:
AIMS-7inv.2025.csv
